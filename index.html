📄 API Endpoints

🔐 Auth

POST /api/v1/auth/register – Register a new user

POST /api/v1/auth/login – Login to your account

📱 Apps

POST /api/v1/apps/create – Create a new app

GET /api/v1/apps/list – List all your apps

DELETE /api/v1/apps/{id} – Delete an app

🔔 Notifications

POST /api/v1/send – Send a push/email notification

POST /api/v1/test-notification – Send a test notification

GET /api/v1/notification/{id}/stats – Get notification stats

POST /api/v1/notification/{id}/pause – Pause a scheduled notification

POST /api/v1/notification/{id}/play – Resume a paused notification

DELETE /api/v1/notification/{id} – Delete a notification

🔑 API Keys

GET /api/v1/validate-key – Validate an API key

POST /api/v1/revoke-key – Revoke and regenerate an API key

👥 Subscribers

POST /api/v1/subscribe – Register a device

GET /api/v1/subscribers – List all subscribers

🔗 Webhooks

POST /api/v1/webhook/register – Register a webhook

GET /api/v1/webhook/list – List all webhooks

DELETE /api/v1/webhook/delete – Delete a webhook

POST /api/v1/webhook/trigger – Trigger a webhook

POST /api/v1/webhook/test – Test a webhook URL

📊 Logs

GET /api/v1/logs/webhooks – View webhook logs

GET /api/v1/logs/subscriptions – View subscription logs

GET /api/v1/logs/notifications – View notification logs

⚙️ Utility

GET /api/v1/brand – Brand information

GET /api/v1/vapid-key – VAPID public key

GET /api/v1/help – Support contact info

GET /api/v1/plans – Pricing plans

👤 Account

POST /api/v1/account/delete – Delete your account

👑 Admin (Password Protected)

GET /api/v1/admin/users – List all users

GET /api/v1/admin/stats – System statistics
